About IconiWave Engine

IconiWave is a minimalist single-page audio visualizer crafted in an editorial aesthetic inspired by Greek art and modern Bauhaus typography.

Features:
  • Built-in real-time generative Ambient Polyphonic Synth
  • Custom audio file player (.mp3, .wav, .ogg, .m4a)
  • Real-time Web Audio Analyser node with multiple Canvas visualizer styles
  • Real-time Dynamic Palette Theme Switcher (6 distinct color themes)
  • Custom Artwork upload & switchable preset collection
  • Warm Vinyl Lo-Fi filter simulation
